## 二、红线兑现（全部有测试锁定）

- ERROR/TIMEOUT/BLOCKED/MANUAL/UNKNOWN **永不自动 PASS**（状态合并分层闭环）；
- query_url 未人工复核**一律 MANUAL**——2026-09-05 真实回放 96 次源查询全 MANUAL，
  与官方站实测拦截（40001/加密响应/521）互相印证；
- "没有取得证据"≠"确认不存在"（NO_DATA 与 PASS 严格分列）；
- 采集与评判分离（adapter 只产客观 Finding，同主体校验两道关卡，评判归 RuleEngine）；
- 主体一致性：同名不同码不误并、缺码不自动认定、模糊相似转人工（含可追溯留痕）;
- 项目条款（Project.terms）真正控制规则；行业/集团不适用显式 NOT_APPLICABLE；
- 不破解验证码、不绕 WAF；真实业务文件只读；内部数据/证据/台账零入库。
