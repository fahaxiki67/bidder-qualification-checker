# 用户验收手册（UAT）

> 交付物验收操作单。每项都有"操作 → 预期"，验收人逐项勾选即可。
> 全程离线/本地，不访问任何真实政府网站（真实联调见 docs/P3R_CHECKLIST.md，另行执行）。

## A. Windows 便携包验收（10 分钟）

准备：从 GitHub Release 下载 `bqc-windows-x64.zip`，解压到任意目录（路径含中文亦可）。

| # | 操作 | 预期 |
|---|------|------|
| A1 | 双击 `start_server.bat` | 弹出控制台窗口，显示 Uvicorn 监听 127.0.0.1:8000；首次运行 SmartScreen 提示→更多信息→仍要运行 |
| A2 | 浏览器打开 http://127.0.0.1:8000 | 显示"投标人资格智能核查系统"首页，页脚版本号正确 |
| A3 | 首页填企业名称（如"演示验收公司"）、勾选条款、场景选"省级限制投标（条款1 FAIL）"→ 开始核查 | 结果页：总体结论 FAIL · 触发否决条款；数据源日志可见；条款结论含判定依据 |
| A4 | 同页换场景"查询失败（ERROR）"重新核查 | 总体 ERROR · 查询失败——**绝不显示"正常/无异常"** |
| A5 | 在结果页数据源查询日志提交一条人工复核（复核人+结论） | 页面出现复核记录；重启程序后仍在 |
| A6 | `Win+R` 输入 `%LOCALAPPDATA%\bqc\data` | 目录存在 `bqc.sqlite3`（数据不落在程序目录） |
| A7 | 命令行 `bqc.exe --version`、`bqc.exe init-db` | 版本号正确；数据库初始化成功 |
| A8 | 关闭控制台窗口，重新双击 bat，打开历史核查 | 历史结果保留；结果页只显示最新一次批次（run_id 可见） |

## C. 报告与证据验收（5 分钟，任一平台）

| # | 操作 | 预期 |
|---|------|------|
| C1 | `bqc report <核查记录id> --excel 样表.xlsx --pdf 报告.pdf` | 两份文件生成；Excel 含 11 个 sheet（含"状态口径说明"） |
| C2 | 打开 Excel"数据源查询日志"sheet | ERROR 行的结论用语为"查询失败"——全表搜不到把失败写成"正常"的单元格 |
| C3 | PDF 打开 | 中文正常显示；汇总含"需人工复核"与批次 run_id |
| C4 | 导入一份禁入名单 JSON（格式见 docs/P3R_CHECKLIST.md #7）后重新核查 | 名单内企业在有效期内 → 条款4 结论 FAIL，同时页面保留"需人工复核"标记 |
| C5 | `bqc verify-evidence --db <数据库路径>` | 输出证据完整性：N 份正常，0 份异常；人为改动证据文件后再跑，损坏被检出 |

## 常见问题

- **双击没反应/闪退**：用命令行在解压目录执行 `bqc.exe serve`（或 `./bqc serve`）看报错；多为端口占用（改 `bqc serve --port 8001`）。
- **杀软/Defender 提示**：exe 未签名，加信任或继续运行。
- **想换数据位置**：设环境变量 `BQC_DB` 指向目标 sqlite 路径。
